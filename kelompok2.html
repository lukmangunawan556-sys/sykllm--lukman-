ENSIKLOPEDIA & MATERI IP ADDRESS

Panduan Ringkas & Konsep Dasar Alamat IP untuk Jaringan Komputer

Apa itu IP Address?

IP Address (Internet Protocol Address) adalah identik numerik unik yang diberikan kepada setiap perangkat yang terhubung ke jaringan komputer berbasis standar TCP/IP. Fungsinya mirip dengan alamat rumah agar paket data dikirim ke tujuan yang tepat.

Struktur IPv4 (32 Bit / 4 Oktet)

IPv4 terdiri dari total 32 bit angka biner yang dibagi menjadi 4 oktet (masing-masing 8 bit) dan dipisahkan oleh titik (Dot-Decimal Notation).

Format: Oktet 1 . Oktet 2 . Oktet 3 . Oktet 4
Contoh: 192 . 168 . 1 . 10
  • Setiap oktet bernilai desimal dari 0 hingga 255 (berasal dari nilai biner 00000000 sampai 11111111).
  • IP Valid: 172.16.254.1 (semua oktet ≤ 255 dan berjumlah 4 oktet).
  • IP Tidak Valid: 192.168.1.256 (oktet 256 melebihi batas 255) atau 10.0.1 (hanya 3 oktet).

Sistem Pengalamatan Classful (Historis)

Secara historis, IPv4 dibagi menjadi 5 Kelas (Class A - E) berdasarkan nilai oktet pertamanya:

Kelas Oktet Pertama Default Mask Peruntukan
Kelas A 1 – 126 255.0.0.0 (/8) Jaringan Skala Sangat Besar (Jutaan Host)
Kelas B 128 – 191 255.255.0.0 (/16) Jaringan Skala Menengah - Besar
Kelas C 192 – 223 255.255.255.0 (/24) Jaringan LAN Lokal / Kecil (Maks 254 Host)
Kelas D 224 – 239 N/A Penggunaan Khusus Multicast
Kelas E 240 – 255 N/A Riset, Eksperimen & Cadangan Masa Depan
Catatan Penting: Sistem kelas A, B, C adalah sistem classful masa lalu. Jaringan internet modern menggunakan sistem CIDR (Classless Inter-Domain Routing) agar tidak terjadi pemborosan alokasi IP Address.

Subnet Mask & Prefix CIDR

Subnet Mask digunakan oleh komputer untuk menentukan bagian mana dari IP Address yang merupakan Network ID (Identitas Jaringan) dan bagian mana yang merupakan Host ID (Identitas Perangkat).

/8
255.0.0.0
8 bit Network
/16
255.255.0.0
16 bit Network
/24
255.255.255.0
24 bit Network

Rumus Menghitung Host Usable

Jumlah IP usable yang dapat dipasangkan pada PC/Device dihitung dengan rumus:

Jumlah Host Usable = 2(32 - Prefix) - 2

*Dikurangi 2 karena IP Pertama digunakan untuk Network ID dan IP Terakhir untuk Broadcast Address.

Alamat IP Khusus yang Tidak Boleh Digunakan Host

  • 1. Network ID (IP Pertama):

    Contoh: 192.168.1.0/24. Alamat ini merupakan identitas/nama segmen jaringan.

  • 2. Broadcast Address (IP Terakhir):

    Contoh: 192.168.1.255/24. Alamat untuk mengirim sinyal/pesan ke seluruh host di subnet.

  • 3. Loopback Address (127.0.0.1 / Blok 127.0.0.0/8):

    Digunakan untuk testing komunikasi internal perangkat itu sendiri (localhost).

Blok IP Private (RFC 1918)

IP Private digunakan bebas di jaringan lokal (LAN) rumah, sekolah, atau kantor tanpa perlu dibeli dari ISP:

  • Kelas A Private: 10.0.0.0 - 10.255.255.255
  • Kelas B Private: 172.16.0.0 - 172.31.255.255
  • Kelas C Private: 192.168.0.0 - 192.168.255.255
